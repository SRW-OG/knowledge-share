## 🚀 如何贡献

### 添加新知识

```bash
# 克隆仓库
git clone https://github.com/SRW-OG/knowledge-share.git

# 创建新文档
# 遵循 5 段式结构：
# 1. 问题现状
# 2. 解决思路与方案对比
# 3. 最佳实践框架
# 4. 具体操作步骤
# 5. 总结与建议

# 提交
git add .
git commit -m "添加: 文档标题"
git push origin main
```

### 文档格式要求

```yaml
---
title: 标题
date: YYYY-MM-DD
category: 分类
tags: [标签1, 标签2]
source: 来源URL
---
```
