# 微信小程序解包逻辑分析

> 来源：Y1Shui | 2026年2月13日 北京

## 一、前言

### 背景描述

日常渗透测试和HW（护网）项目中，小程序是重要的突破口。之前使用的JS工具经常卡死或解包失败。

### 常用工具

| 工具 | 说明 |
|------|------|
| fine | 旧版本有源码可参考 |
| tscanplus | 常用的小程序解包工具 |

本文通过分析 fine 项目的源码，详细讲解微信小程序的解包原理。

## 二、源码获取与分析

### 项目结构

```
fasnow/fine
├── backend/       # 核心处理逻辑
│   └── service/service/wechat/
│       ├── bridge.go    # 解包入口
│       └── wechat.go    # 小程序包处理
├── build/         # 打包资源（ico、manifest等）
└── frontend/     # 前端资源
```

### 关键代码入口

解包方法位于 `backend\service\service\wechat\bridge.go` 的 `decompile` 方法。

## 三、解密流程详解

### 3.1 获取小程序包

通过 `GetMiniAppWxapkgs` 方法，根据输入的 appid 和 version 获取小程序包的路径。

### 3.2 AES 解密

```python
# 解密类型：AES
# Key：小程序的 appid（代码中写的是 wxID）
# Salt：固定值
# IV：固定值

# 通过 salt 获取 PBKDF2 加密后的密钥
```

**解密步骤：**
1. 前6字节忽略
2. 6-1024字节： AES解密
3. 1030字节之后： XOR解密
   - 密钥：0x66 或 appid倒数第二个字符的ASCII码

### 3.3 反编译处理

调用 `UnpackWxapkg` 方法：
1. 解析包内的结构
2. 判断文件类型
3. 针对不同文件类型进行美化处理
4. 写入文件到指定目录

## 四、实战应用

### 渗透测试中的应用

1. **信息收集**：通过小程序获取后端API接口
2. **漏洞挖掘**：分析小程序源码发现逻辑漏洞
3. **突破口**：小程序往往能打开新的攻击面

### 工具推荐

- **fine**: https://github.com/fasnow/fine
- **tscanplus**: 集成多种功能的综合工具

## 五、总结

通过分析 fine 源码，更深入理解了微信小程序的解包原理：

1. **双重加密**：AES + XOR
2. **平台差异**：Windows需要解密，Mac直接返回明文
3. **核心要素**：appid作为密钥种子

理解原理有助于更好地进行渗透测试和安全研究。
