## 二、GitHub 重点项目

### 2.1 A股年报爬虫（中文）

#### 🌟 legeling/Annualreport_tools — 208 Stars（最高）
**定位**: 巨潮资讯网年报爬取 + PDF转TXT + 关键词分析

**核心功能**:
```
1. report_link_crawler.py    → 按板块/行业爬取年报链接
2. pdf_batch_converter.py     → 批量下载PDF + 转换为TXT
3. text_analysis.py           → 多进程关键词分析 + Excel导出
```

**特点**:
- 提供了 **2004-2023 年年报链接表** (`AnnualReport_links_2004_2023.xlsx`)，无需重复爬取
- 支持按行业/板块筛选
- 限速机制，保护服务器
- **缺点**: 只是关键词统计，不能提取"主营构成比例"这种结构化数据

**链接**: https://github.com/legeling/annualreport_tools

### 2.2 美股/SEC 年报提取（可参考）

#### astonishedrobo/sec-llm-insights — ⭐强烈推荐参考
**定位**: 分析10-K年报，提取营收构成（Segment Revenue）

**核心功能**:
```
输入: 公司 ticker (如 AAPL)
  ↓
1. fetch_10k.py → 自动下载10-K原文
2. analyze() → LLM分析，输出结构化JSON
  ↓
输出: {
  revenue_segments: [
    {"segment": "iPhone", "revenue": 200.5, "unit": "billion"},
    {"segment": "Services", "revenue": 20.2, "unit": "billion"}
  ]
}
```

**特点**:
- ✅ 提取营收分项（segment）和具体金额
- ✅ 支持按年份对比
- ✅ 有可视化输出（条形图）
- 技术栈: Flask + Anthropic API + sec-edgar-downloader + sec-parser

**链接**: https://github.com/astonishedrobo/sec-llm-insights

---

#### edgartools — 最完整的SEC工具库
**定位**: Python库访问SEC EDGAR所有 filings

**链接**: https://github.com/dgunning/edgartools

## 三、核心技术流程

### 3.1 年报 → 结构化数据 完整流程

```
┌─────────────────────────────────────────────────────────────┐
│                    完整技术流程                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Step 1: 爬取年报 PDF                                        │
│  ├── cninfo_spider / report_link_crawler                   │
│  ├── 数据源: 巨潮资讯网                                      │
│  └── 输出: PDF文件批量下载                                    │
│                    ↓                                        │
│  Step 2: PDF → TXT 文本                                      │
│  ├── pdfplumber / PyMuPDF                                   │
│  └── 输出: 纯文本（保留表格结构）                              │
│                    ↓                                        │
│  Step 3: 业务构成提取                                        │
│  ├── 关键词定位: "主营业务收入" / "分行业" / "分产品"          │
│  ├── 正则提取: 金额 + 比例                                   │
│  └── 输出: 结构化表格                                         │
│                    ↓                                        │
│  Step 4: LLM 语义增强                                        │
│  ├── 上下文理解: 判断正负向影响                               │
│  ├── 产业链映射: 识别供应商/客户                               │
│  └── 输出: JSON结构化数据                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 主营构成提取示例

年报中常见表述：
```
"报告期内，公司主营业务包括：白卡纸销售收入 85.3亿元，占比 72.5%；"
"文化纸收入 24.6亿元，占比 20.9%；"
"溶解浆收入 7.8亿元，占比 6.6%。"
```

提取后结构化输出：
```json
{
  "company": "晨鸣纸业",
  "year": 2024,
  "main_business": [
    {"segment": "白卡纸", "revenue": 85.3, "unit": "亿元", "ratio": 0.725},
    {"segment": "文化纸", "revenue": 24.6, "unit": "亿元", "ratio": 0.209},
    {"segment": "溶解浆", "revenue": 7.8, "unit": "亿元", "ratio": 0.066}
  ]
}
```

## 四、关键难点与解决方案

### 4.1 年报获取

| 难点 | 解决方案 |
|------|----------|
| 反爬限制 | 限速 + 代理IP池 |
| PDF下载不完整 | MD5校验 + 完整性验证 |
| 年报超链接表 | 直接用 `Annualreport_tools` 提供的xlsx |

### 4.2 业务构成提取

| 难点 | 解决方案 |
|------|----------|
| 格式不统一 | 正则 + LLM 双重提取 |
| 非结构化表述 | 用LLM做语义理解 |
| 表格跨越多页 | pdfplumber 表格合并 |
| 比例数据缺失 | 用绝对金额反推比例 |

### 4.3 产业链关联

| 难点 | 解决方案 |
|------|----------|
| 如何知道A公司是B的上游 | 年报中"主要客户/供应商"章节 |
| 行业分类映射 | 同花顺行业分类 + 证监会行业分类 |
| 传导方向判断 | 规则引擎 + LLM 推理 |

## 七、结论

1. **A股年报爬取**: `legeling/Annualreport_tools` (208⭐) 是最成熟方案，已提供链接表
2. **业务构成提取**: 目前没有现成的"年报→主营构成比例"的开源工具，需自行开发
3. **可参考美股方案**: `sec-llm-insights` 的"营收分项提取"模式可以直接借鉴到A股
4. **核心技术**: PDF解析 → 正则提取金额 → LLM补全语义 → 知识图谱

**对于产业链分析来说，年报中的"主要客户"和"主要供应商"章节与"主营构成"同样关键。**
