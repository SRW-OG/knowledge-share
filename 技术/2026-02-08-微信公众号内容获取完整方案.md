# 微信公众号内容获取完整方案

> 2026-02-08 | 技术研究

## 背景

微信公众号文章是优质中文技术内容的重要来源，但微信对内容有严格保护，需要特殊方法获取。

## 可行方案

### 方案1: 搜狗微信搜索

**状态**: ✅ 可行

**地址**: https://weixin.sogou.com/

**优点**:
- 可搜索公众号文章
- 免费使用
- 无需登录

**缺点**:
- JavaScript 动态渲染
- 部分链接需要验证
- 反爬虫措施

**使用方法**:
```python
import requests

headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    "Accept": "text/html",
}

response = requests.get(
    "https://weixin.sogou.com/weixin",
    params={"query": "网络安全", "type": 2},
    headers=headers
)
```

### 方案2: 微信读书搜一搜

**地址**: https://weread.qq.com/wr/search?query=关键词

**优点**:
- 可能有更好的访问性
- 包含部分公众号内容

### 方案3: Chrome with Remote Debugging

**状态**: ⚠️ 需要配置

**启动命令**:
```bash
chromium-browser \
  --headless=new \
  --remote-debugging-port=9222 \
  --remote-debugging-address=127.0.0.1 \
  --user-data-dir=/tmp/wechat-chrome \
  "https://weixin.sogou.com/"
```

**使用 CDP API**:
```python
import requests

# 获取页面
response = requests.get("http://127.0.0.1:9222/json")
pages = response.json()

# 导航到 URL
requests.put(
    "http://127.0.0.1:9222/json/new",
    params={"url": "https://weixin.sogou.com/..."}
)
```

### 方案4: browser-use-skill

**状态**: ⚠️ 需要 gateway

OpenClaw 的 browser-use-skill 运行在端口 9223，需要通过 gateway 访问。

### 方案5: Chrome DevTools MCP

**参考**: https://github.com/ChromeDevTools/chrome-devtools-mcp

```bash
npx -y chrome-devtools-mcp@latest \
  --browserUrl=http://127.0.0.1:9222 \
  --headless
```

## 实际测试结果

| 方案 | 状态 | 说明 |
|------|------|------|
| 搜狗微信搜索 | ✅ 可行 | 可以获取 HTML，需要处理 JS 渲染 |
| 直接 requests | ⚠️ 部分 | 只能获取骨架，内容由 JS 动态加载 |
| Chrome CDP | ⚠️ 需要配置 | 端口 9222 可用 |
| browser-use | ⚠️ 需要 gateway | 端口 9223，需要 OpenClaw |

## 推荐工作流

1. **简单抓取**: 使用 curl/web_fetch 获取公开页面
2. **动态内容**: 使用 Chrome CDP 渲染后提取
3. **批量处理**: 结合 Playwright/Selenium
