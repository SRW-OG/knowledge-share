# 网络安全文档自动化整理与 RAG 知识库构建

## 核心要点

针对文件混乱、需要深度理解内容、且带有专业垂直领域（网络安全）的情况，简单的文件名分类已经不够用了。将文件转化为 Markdown 并构建 RAG（检索增强生成）知识库是最专业的做法。这样不仅整理了文件，还直接拥有了一个"网络安全专家助手"。

---

## 第一步：文档预处理（转为 Markdown）

推荐使用微软的 MarkItDown 或 Marker。

**安装命令：**
```powershell
pip install markitdown ollama
```

**执行转换：** 编写一个简单的循环脚本，将 .docx, .pdf, .pptx 统一转为 .md。

**为什么这么做？** Markdown 体积小、去除了冗余格式，且模型对 Markdown 的结构（标题、列表）识别度最高。

---

## 第二步：自动化整理脚本

这个脚本会遍历文件夹，如果是文档就提取内容，问 Qwen 该怎么起名，然后自动移动到新文件夹。

```python
import os
import shutil
import ollama
from markitdown import MarkItDown

# --- 配置区 ---
SOURCE_DIR = r'C:\你的待整理目录'  # 修改为你的路径
TARGET_DIR = r'C:\整理后的文档'    # 修改为你的路径
MODEL_NAME = 'qwen2.5:14b'          # 确认你已执行 ollama run qwen2.5:14b

md = MarkItDown()

def get_smart_name(file_path, content_snippet):
    """请求 Qwen2.5 根据内容生成符合你逻辑的文件名"""
    prompt = f"""
    你是一个网络安全专家。请分析以下文档内容片段，并给出一个规范的中文文件名。
    内容片段：{content_snippet[:1000]}  # 截取前1000字
    
    要求：
    1. 格式必须为：[类别-二级分类]具体描述
    2. 类别参考：国际标准、国内标准、调研报告、方案实践、工作文档
    3. 只输出文件名，不要有任何额外解释。
    """
    try:
        response = ollama.chat(model=MODEL_NAME, messages=[{'role': 'user', 'content': prompt}])
        return response['message']['content'].strip().replace('/', '-')
    except Exception:
        return None

if __name__ == "__main__":
    if not os.path.exists(TARGET_DIR):
        os.makedirs(TARGET_DIR)
    
    for root, dirs, files in os.walk(SOURCE_DIR):
        for file in files:
            file_path = os.path.join(root, file)
            ext = os.path.splitext(file)[1].lower()
            
            # 仅处理常见文档格式
            if ext in ['.pdf', '.docx', '.pptx', '.xlsx', '.txt']:
                print(f"正在处理: {file}...")
                try:
                    # 1. 提取内容
                    result = md.convert(file_path)
                    content = result.text_content
                    
                    # 2. 获取 AI 建议名称
                    new_name = get_smart_name(file, content)
                    
                    if new_name:
                        # 3. 创建分类文件夹并移动
                        category = new_name.split(']')[0].replace('[', '')
                        cat_path = os.path.join(TARGET_DIR, category)
                        os.makedirs(cat_path, exist_ok=True)
                        target_file = os.path.join(cat_path, f"{new_name}{ext}")
                        shutil.copy(file_path, target_file)
                        print(f" -> 已归类至: {category}")
                except Exception as e:
                    print(f" ! 处理失败 {file}: {e}")
    
    print("整理完成！")
```

**脚本使用说明：**
- **逻辑说明：** 脚本不会删除原文件，而是通过 `shutil.copy` 复制到新目录，防止 AI 误判导致文件丢失。
- **内容识别：** 它会读取文档前 1000 个字发给 Qwen，这对于识别"网络安全标准"或"调研报告"的标题和摘要绰绰有余。
- **针对随机命名：** 即使原名叫 `12345.pdf`，只要里面写的是《NIST 零信任架构》，Qwen 也会将其重命名为 `[国际标准-NIST]零信任架构.pdf`。

## 第三步：利用 Cherry Studio 构建知识库

Cherry Studio 内置了非常出色的 RAG（知识库）功能。

1. **打开 Cherry Studio：** 点击左侧导航栏的"知识库"图标
2. **创建知识库：** 点击"新建知识库"，命名为"网安标准与实践"
3. **配置 Embedding（嵌入模型）：**
   - 知识库需要一个 Embedding 模型来"读懂"语义
   - 推荐：在 Ollama 中下载 `nomic-embed-text` 或 `bge-m3`
   - 在 Cherry Studio 知识库设置中，选择这些模型作为嵌入引擎
4. **导入 Markdown：** 将第一步生成的 md 文件批量拖入，Cherry Studio 会自动对其进行切片、向量化

## 第四步：物理文件的最终整理

由于不想按文件类型分，而是按"意义"分，建议采用"维度分类法"创建文件夹：

```
01_国际标准_ISO_NIST
02_国内标准_等保_关保
03_行业调研_零信任_态势感知
04_工作手记_项目周报
```

**针对"压缩包"的特殊处理：**
- **解压预览：** 先用脚本或手动解压
- **摘要提取：** 如果里面文件太多，只提取 README 或 目录树 文本给 Qwen2.5 看
- **重新打包：** 根据 Qwen2.5 给出的建议，重新命名并归类

## 第五步：使用 Qwen2.5:14b 进行智能分类与重命名

现在文档已经变成了可搜索的知识库，可以让模型帮你"出谋划策"来整理物理文件：

**对话模式：** 在 Cherry Studio 中选择 qwen2.5:14b 并关联刚才创建的知识库

**发送指令：**
```
我有一个文件名叫 XYZ_001.md，请根据知识库内容告诉我：
1. 这个文档是关于哪个标准的（国际/国内）？
2. 它的具体主题是什么（调研报告/方案/实践）？
3. 请给我起一个符合内容的中文文件名，格式为：[类别]具体名称_日期。
```

**导入 Cherry Studio：**
- 等脚本跑完，得到的将是一个结构清晰、命名规范的文件夹
- 打开 Cherry Studio，点击 知识库 -> 添加文件夹，选择刚才脚本生成的 TARGET_DIR
- 由于文件名已经带有语义，Cherry Studio 的向量搜索 (RAG) 准确率会大幅提升

## 进阶方案：使用"本地双链笔记"

如果整理这些文档是为了长期工作，建议在完成 Markdown 转换后，使用 Obsidian 配合 Ollama 插件。

**优势：** 可以建立文档之间的"链接"。比如《等保2.0》和某个《测评方案》之间可以连线。

**Cherry Studio 角色：** 作为快速查询和重命名咨询台。
