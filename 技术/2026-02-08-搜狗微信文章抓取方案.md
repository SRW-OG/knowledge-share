# 搜狗微信文章抓取方案

> 2026-02-08 | 技术研究

## 方案概述

通过搜狗微信搜索（https://weixin.sogou.com/）抓取公众号文章。

## 可行性

✅ 搜狗微信可以正常搜索和返回文章列表  
✅ 文章链接可以提取  
⚠️ 部分链接需要点击验证

## 使用方法

```bash
# 搜索公众号文章
python3 wechat_scraper.py search "网络安全" --limit 10

# 获取文章详情
python3 wechat_scraper.py fetch "https://weixin.sogou.com/link?url=..."
```

## 完整脚本

```python
#!/usr/bin/env python3
"""
搜狗微信文章抓取工具
"""

import requests
import re

class WechatScraper:
    def __init__(self):
        self.session = requests.Session()
        self.headers = {
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
            "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
            "Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8",
            "Referer": "https://weixin.sogou.com/"
        }
    
    def search(self, keyword, limit=20):
        """搜索公众号文章"""
        url = "https://weixin.sogou.com/weixin"
        params = {
            "query": keyword,
            "type": 2,
            "page": 1
        }
        
        response = self.session.get(url, params=params, headers=self.headers)
        articles = self._parse_search_results(response.text)
        return articles[:limit]
    
    def _parse_search_results(self, html):
        """解析搜索结果"""
        articles = []
        pattern = r'/link\?url=([^"]+)"[^>]*>([^<]+)</a>'
        matches = re.findall(pattern, html)
        
        for link, title in matches:
            articles.append({
                "title": title.strip(),
                "link": f"https://weixin.sogou.com/link?url={link}"
            })
        
        return articles
    
    def fetch_article(self, url):
        """获取文章内容"""
        response = self.session.get(url, headers=self.headers, allow_redirects=True)
        return response.url


if __name__ == "__main__":
    scraper = WechatScraper()
    articles = scraper.search("网络安全", limit=5)
    
    for i, art in enumerate(articles, 1):
        print(f"{i}. {art['title']}")
        print(f"   {art['link']}")
```
