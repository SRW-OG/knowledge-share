# MDUT-Extend (MDUT增强版) V1.3.0 发布

> 作者：s0cke3t | 公众号：警戒线安全 | 发布日期：2026年3月18日

## 前言

时光荏苒，距离上个版本 v1.2.0 发布至今已经过去了一年有余。这次能高效地清掉堆积如山的 Issue，要感谢 AI 时代的帮助。

本次更新整合了 AI 能力与社区贡献代码，诚意拉满。

---

## 更新内容

### 1. 新增 MongoDB 数据库利用

在此版本中，正式加入了对 **MongoDB** 类型数据库的支持。

- **CVE-2025-14847** 利用支持
- 支持自定义最大和最小偏移量 (Offset)
- 利用结果保存为 `.bin` 二进制文件，方便深度分析

![MongoDB利用截图](./assets/mongodb-01.png)

### 2. 数据库存活扫描功能

新增数据库存活扫描功能，针对已添加的数据库条目进行批量连接测试，快速筛选可用数据库实例。

![数据库扫描截图](./assets/db-scan.png)

### 3. Redis 漏洞利用增强

针对 Redis 数据库，重点加强了两个漏洞的利用能力：

#### CVE-2025-49844
- 支持漏洞扫描与深度利用
- 利用模式支持**无回显命令执行**以及**OOB 带外回显**
- 集成**反弹 Shell** 功能

![Redis CVE-2025-49844截图](./assets/redis-01.png)

#### CVE-2022-0543
- 支持命令执行功能
- 支持**自定义 SO 库路径**，适配复杂利用场景

![Redis CVE-2022-0543截图](./assets/redis-02.png)

### 4. Oracle 大文件模式上传与下载

针对 Oracle 数据库，优化文件传输逻辑，新增大文件上传和下载模式，解决传输大体积文件时的超时或截断问题。

![Oracle大文件截图](./assets/oracle-01.png)

### 5. Mssql 综合利用与提权增强

Mssql 模块得到史诗级加强：

- 新增 **Godpotato** 等多种提权类型
- 支持直接加载 **Shellcode** 功能
- 新增 **Mssql 综合利用面板**，集成常用注入、执行与文件操作

![Mssql提权截图](./assets/mssql-01.png)

> ⚠️ **特别声明**：Mssql 增强部分代码参考了互联网各大『代工巨头』和无私分享的师傅们的源码，感谢各位老师傅的馈赠！

## Bug 修复

| 模块 | 修复内容 |
|------|----------|
| **Oracle** | 修复 `ORA-12505` 问题，支持 SID 和 Service Name 两种连接方式 |
| **Oracle** | 修复函数初始化失败及 Powershell 右括号缺失问题 |
| **Oracle** | 解决文件下载时 `ORA-24345` 异常 |
| **Redis** | 修复 Linux 环境下计划任务名称随机化问题 |
| **Postgresql/Redis** | 修复驱动程序异常、主从复制失败及 SocketException 等稳定性问题 |
