# Webpack自动化解析工具 Webpack_extract

## 0x01 工具介绍

**Webpack_extract** 是一款开源的 Chrome 端 JS 逆向辅助工具，专为红队信息收集、SRC 挖掘打造。

### 核心功能

- 🔑 **一键提取映射**：自动提取 Webpack 映射关系
- ⚡ **自动加载分析**：智能分析自动加载逻辑
- 🛠️ **硬核功能**：一站式搞定 Webpack 打包 JS 解析难题

### 工具特点

- 告别手动抠包的繁琐低效
- 历经实战打磨优化
- 攻克跨域、兼容性等痛点
- 已在多轮攻防对抗、SRC 挖掘场景中成功应用

### 适用场景

- 红队信息收集
- SRC 挖掘
- 渗透测试前期排查
- 前端逆向
