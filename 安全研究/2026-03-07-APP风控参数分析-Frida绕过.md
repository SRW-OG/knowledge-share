**问题**：直接 hook dlopen 会让手机卡死，因为同时加载了特征 so

### 2. Hook Clone 函数（推荐）

**原理**：Clone 是 Linux 创建线程的底层调用，Hook 它可以：
- 知道每个线程的详细信息
- 谁创建的
- 线程函数在哪
- 什么时候创建的
- 定位反调试线程 → 分析它 → 干掉它

```javascript
function hook_clone() {
    var clone = Module.findExportByName('libc.so', 'clone');
    Interceptor.attach(clone, {
        onEnter: function(args) {
            // 读取线程函数
            var real_func = args[3].add(96).readPointer();
            var module = Process.findModuleByAddress(real_func);
            if (module) {
                var offset = real_func.sub(module.base);
                console.log("SO名称:", module.name);
                console.log("函数地址:", real_func);
                console.log("偏移:", offset);
            }
        }
    });
}
```

### 3. pthread_internal_t 结构体

## 三、Android 线程创建流程

### 三种线程类型
1. **Java 线程**：Android 虚拟机线程
2. **Native 线程**：只能执行 C/C++
3. **Native 线程（执行 Java）**：既能执行 C/C++ 也能执行 Java

### 创建流程

```
Java: Thread.start()
    ↓
nativeCreate (JNI)
    ↓
Thread_nativeCreate (C++)
    ↓
CreateNativeThread()
    ↓
pthread_create()
    ↓
clone() → Linux 内核
```

### 关键点
- `pthread_create` 调用 `clone` 系统调用
- `clone` 参数 `CLONE_VM, CLONE_FS, CLONE_FILES` 等决定线程间共享的资源
- fork vs 线程：fork 的 flags = SIGCHLD

        "os_name": "REL",
        "os_ver": "10",
        "platform": "android",
        "resolution": "1440*2712",
        "time_stamp": timestamp
    }
    
    # RSA 加密
    public_key_pem = "-----BEGIN PUBLIC KEY-----..."
    public_key = RSA.import_key(public_key_pem)
    cipher = PKCS1_v1_5.new(public_key)
    max_chunk = public_key.size_in_bytes() - 11  # 117字节
    
    json_string = json.dumps(device_info, separators=(',', ':'))
    encrypted_chunks = []
    for i in range(0, len(json_string), max_chunk):
        chunk = json_string[i:i+max_chunk].encode('utf-8')
        encrypted_chunks.append(cipher.encrypt(chunk))
    
    # Base64 编码
    return base64.b64encode(b''.join(encrypted_chunks)).decode('utf-8')
