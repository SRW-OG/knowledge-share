# Windows服务器三级等保安全加固

## 一、问题现状 (Current Status & Problem Analysis)

### 背景描述

Windows 服务器是企业核心业务系统的重要承载平台，其安全性直接关系到企业信息系统的整体安全等级。网络安全等级保护 2.0（简称等保 2.0）对三级系统提出了更高的安全要求，需在身份鉴别、访问控制、安全审计、入侵防范等多个方面进行加固。

### 风险评估

- **身份鉴别风险**：弱口令、默认账户、未启用密码复杂度等可能导致未授权访问
- **审计缺失风险**：未启用安全审计将无法追踪重要安全事件
- **入侵风险**：多余服务、默认共享、高危端口可能成为攻击入口

### 影响范围

- 所有 Windows 服务器（尤其 Windows Server 2016/2019/2022）
- 三级等保测评项目

## 二、解决思路与方案对比 (Solution Options & Analysis)

### 方案一：手动加固

通过本地安全策略、注册表、服务管理等方式手动配置。

| 维度 | 分析 |
|------|------|
| 优点 | 无需额外工具、成本低 |
| 缺点 | 操作繁琐、易遗漏、难以批量部署 |
| 实施难度 | 中等 |
| 成本 | 低 |

### 方案二：域控制器集中管理

通过 Active Directory 域策略统一管理。

| 维度 | 分析 |
|------|------|
| 优点 | 集中管理、批量部署、一致性好 |
| 缺点 | 需要域环境、配置复杂 |
| 实施难度 | 高 |
| 成本 | 中等 |

### 方案三：脚本自动化加固（本文推荐）

使用批处理脚本实现自动化加固。

| 维度 | 分析 |
|------|------|
| 优点 | 快速部署、可重复执行、易于维护 |
| 缺点 | 需要测试验证 |
| 实施难度 | 低 |
| 成本 | 低 |

## 四、具体操作步骤 (Implementation Steps)

### 前置准备

- 备份当前系统配置
- 创建系统还原点
- 建议在测试环境验证后再生产部署

### 4.1 身份鉴别

#### a) 用户身份标识与密码复杂度

**要求**：应对登录的用户进行身份标识和鉴别，身份标识具有唯一性，身份鉴别信息具有复杂度要求并定期更换。

**操作步骤**：

1. **强制要求输入用户名和密码**
   - 运行：`netplwiz`
   - 勾选"要使用本计算机，用户必须输入用户名和密码"

2. **查看账户口令修改时间**
   ```cmd
   net user <用户名>
   ```

3. **查看系统账户**
   - 运行：`lusrmgr.msc`
   - 检查系统默认用户 `administrator` 和 `Guest`
   - Guest 账户应默认禁用
   - administrator 不存在默认口令

4. **取消密码永不过期**
   - 在用户属性中取消勾选"密码永不过期"

5. **配置密码策略**
   - 运行：`secpol.msc` → 账户策略 → 密码策略
   - 启用密码复杂度要求
   - 密码复杂度最小值：8 位
   - 密码最长使用期限：90 天

#### b) 登录失败处理与会话锁定

**要求**：应具有登录失败处理功能，应配置并启用结束会话、限制非法登录次数和当登录连接超时自动退出等相关措施。

**操作步骤**：

1. **配置账户锁定策略**
   - 运行：`secpol.msc` → 账户策略 → 账户锁定策略
   - 开启登录失败处理功能

2. **配置屏幕保护程序**
   - 控制面板 → 外观 → 显示 → 屏幕保护程序设置
   - 启用屏保
   - 勾选"在恢复时显示登陆屏幕"

#### c) 远程管理安全

**要求**：当进行远程管理时，应采取必要措施、防止鉴别信息在网络传输过程中被窃听。

**操作步骤**：

- 本地管理（KVM 等硬件方式）：默认满足
- 远程桌面管理：
  - 运行：`gpedit.msc` → 管理模板 → Windows 组件 → 远程桌面服务 → 远程桌面会话主机 → 安全
  - 启用"远程（RDP）连接要求使用指定的安全层"

### 4.2 安全审计

#### a) 启用安全审计功能

**要求**：应启用安全审计功能，审计覆盖到每个用户，对重要的用户行为和重要安全事件进行审计。

**操作步骤**：

- 运行：`secpol.msc` → 本地策略 → 审核策略
- 启用安全设置审核成功、失败

#### b) 审计记录保护

**要求**：应对审计记录进行保护，定期备份（留存 6 个月并备份在异机），避免受到未预期的删除、修改或覆盖等。

**操作步骤**：

1. 运行：`eventvwr.msc` → Windows 日志 → 应用程序 → 属性
2. 调整日志最大大小
3. 配置备份策略
4. 安装日志审计代理插件，将日志发送至日志审计服务器

#### c) 审计进程保护

**要求**：应对审计进程进行保护，防止未经授权的中断。

**操作步骤**：

- 运行：`secpol.msc` → 本地策略 → 用户权限分配
- 查看"管理审核和安全日志"策略项
- 把审计管理员加入审核权限

### 4.3 入侵防范

#### a) 最小化安装原则

**要求**：应遵循最小安装的原则，仅安装需要的组件和应用程序。

**操作步骤**：

1. **检查多余组件**
   - 运行：`dcomcnfg` → 组件服务 → 计算机 → 我的电脑
   - 核查是否存在多余的组件

2. **检查多余服务**
   - 运行：`appwiz.cpl`
   - 核查是否装有多余的服务

#### b) 关闭高危服务和共享

**要求**：应关闭不需要的系统服务、默认共享和高危端口。

**操作步骤**：

1. **检查系统服务**
   - 运行：`services.msc`
   - 检查以下服务是否已启动：
     - Remote Registry
     - Server
     - Messenger
     - Task Scheduler

2. **检查共享开启情况**
   ```cmd
   net share
   ```

3. **关闭默认共享（批处理自启动法）**

创建批处理文件 `disable_share.bat`：

```batch
net share ipc$ /delete
net share admin$ /delete
net share c$ /delete
net share d$ /delete
net share e$ /delete
net share f$ /delete
...
```

保存为 `*.bat` 文件，并设置开机自启动。

## 五、总结与建议 (Summary & Recommendations)

### 成效回顾

通过三级等保安全加固，可实现：

1. **身份鉴别**：密码复杂度提升，账户锁定机制启用，登录失败处理配置
2. **安全审计**：安全事件审计全覆盖，审计记录保护机制建立
3. **入侵防范**：最小化安装，关闭高危服务，禁用默认共享

### 后续维护

1. **定期检查**：定期检查安全策略配置是否生效
2. **日志分析**：定期分析安全日志，发现潜在威胁
3. **漏洞更新**：及时安装系统安全补丁
4. **配置备份**：定期备份安全配置，以便快速恢复
