# 谈一谈红队中的社工钓鱼姿势（上）

## 1. 前言

红队越来越难打了起码对我来说今年的几场红队中社工钓鱼成为了必定要考虑的姿势，现在的目标也不是完全能拿有效RCE的day拿下的，当然比有巨多0day的大佬来说还真不比上。大厂的安全研究部门以及厂商的公益src从day的产出上来说，拎出来太能打了。并且这两年也没有非常核弹级的nday，已经不是前些年拿着shiro一键利用工具梭哈就能解决靶标的年代了。

所以起码在目前阶段而言甚至明年或者后年的红队同学们来讲，**钓鱼的姿势可能在一定程度上能决定在一场比赛中能拿到什么样的名次**。

---

## 2. 钓鱼（社工钓鱼）

### 2.1 钓鱼的优势

- 钓鱼的成果最大化的好处是**能实现突破边界**以及**快速的获取办公网、业务网的大致情况**以及部分业务系统的**web权限**
- 毕竟目前人的习惯上来讲，**浏览器记住密码**这个习惯不可能改掉，毕竟太好使了

### 2.2 为什么选择钓鱼

- **口令复用的问题**：对于大多数人来讲，不管工商银行还是说中国银行等等，取款密码大部分人的习惯是一致的，QQ密码还是微信密码对于同一个人来说复用的概率也很高

### 2.3 钓鱼方式方法

| 钓鱼方式 | 描述 |
|----------|------|
| **邮件钓鱼** | 攻击者发送伪装成信任来源（如银行、社交网站、电子商务网站等）的电子邮件给受害者，欺骗受害者点击链接或下载附件，并在其中输入个人敏感信息 |
| **社交媒体钓鱼** | 攻击者在社交媒体平台上伪装成真实账户或虚假人物，与受害者进行互动并引导受害者访问恶意站点或提供个人信息 |
| **手机钓鱼** | 攻击者通过短信或电话，欺骗受害者前往恶意站点或者提供个人信息 |

---

## 3. 近源攻击

### 3.1 badUSB投放

攻击者通过近源利用U盘等可移动设备，将病毒或木马程序隐藏在其中，并将其留在可能被特定目标（如公司）发现的地方，以便感染目标计算机系统。

### 3.2 WIFI破解

攻击者利用近源方式目标单位的无线网络进行探测以及尝试破解，当WIFI未和业务网进行隔离时，可直接突破边界进行横向。

### 3.3 启动盘近源终端

攻击者通过近源的方法接近目标单位的终端，通过启动盘增加管理员用户，实现突破边界，进行横向攻击。同时可以通过抓取管理员用户的密码横向进行密码喷洒。

---

## 4. 实战案例

> 只讲方式方法，不谈免杀。除去近源的方式外，基本上所有的钓鱼和社工方式均需要免杀的参与。暂且不提横向工具的免杀，**上线应用的免杀是进行钓鱼前首要需要解决的问题**。

### 4.1 实战钓鱼一：邮箱钓鱼

**场景：靶标学校**

对于学校的钓鱼比较简单，最先考虑的问题应该是学号等。学校的业务系统涉及第二学科、教务等系统。但需考虑的首要问题是，账号怎么获得。

#### 通过QQ邮箱钓鱼需要注意以下几个方面

1. **注册qq邮箱后需要将被绑定的手机号删除掉**
2. **开启英文邮箱**
3. **修改邮箱发送为英文邮箱**，最好使用信息搜集的靶标的相关用户的姓名全拼等
4. **增加qq邮箱的资料卡**或者设置签名

![QQ邮箱英文模式设置](./assets/01_qq_email_english_mode.png)

*上图：QQ邮箱英文模式设置界面*

#### 账号密码钓鱼

- 导航的钓鱼超链要到位，这种钓鱼考虑到方便目标点击跳转，也方便无复制点击调转实现钓鱼
- **钓鱼网站的制作需要发件人自己测试好，当首次提交后自动跳转正确的网址**

![钓鱼邮件效果示例](./assets/02_phishing_email_sample.png)

*上图：钓鱼邮件效果示例，展示了伪造的单位邮件*

#### 数据接收机制

- 可以考虑使用**钉钉的机器人接口**
- **注意**：钉钉机器人的接口一分钟调用次数为20次，存在丢包的情况

![钉钉机器人配置](./assets/03_dingtalk_robot.png)

*上图：钉钉机器人Webhook配置界面*

#### 注意事项

> 现在腾讯的机制是同一个账号给陌生人发邮件，当发送条数一次大于30条左右就会邮件自动进入黑名单。在22年之前，一次能100封左右。

#### 实战效果

- 批量下发文件后上线效果，总共是**上线终端98台**
- 客户端上线手速一定要快，做好权限维持才是可持续输出的先决条件

![钓鱼上线效果图](./assets/04_phishing_result.png)

*上图：钓鱼批量上线效果图，显示98台终端上线*

### 4.2 实战钓鱼二：系统任务下发

**获取web应用系统权限，通过系统的文件管理下发邮件**

- 系统文件管理下发的功能基本上综合系统或者SSO都有
- 上线效果也是很能打

![系统任务下发界面](./assets/05_system_task下发.png)

---

### 4.3 实战钓鱼三：利用系统短信接口

这是某个行动中的某个靶标单位，系统内的短信接口很好用。这里的短信接口不单单可以发送给本单位人员，包括到访单位的数十万人员均可发送。

#### 目标群体选择

1. **该单位所有人员**
2. **社区YY人员（社区为重点）**：一张网且防护弱
3. **发送内容需要考量**

### 4.4 传统社工

传统社工其实更简单，但是成功率比较低。案例包括：

1. 根据获取到的信息被VX钓鱼，突破专有云
2. 利用微信钓鱼，短平快，最后上向日葵

## 5. 总结

### 钓鱼攻击要点

| 要点 | 说明 |
|------|------|
| 免杀是关键 | 上线应用的免杀是进行钓鱼前首要需要解决的问题 |
| 账号收集 | 针对学校等目标，学号等是首要考虑的账号类型 |
| 钓鱼方式 | 邮件钓鱼、短信钓鱼、微信钓鱼等多种方式结合 |
| 权限维持 | 客户端上线手速要快，做好权限维持 |

### 攻击链总结

```
信息收集 → 账号获取 → 钓鱼制作 → 免杀处理 → 批量发送 → 权限维持 → 横向渗透
```
