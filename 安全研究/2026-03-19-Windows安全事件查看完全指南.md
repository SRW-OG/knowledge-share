# Windows安全事件查看完全指南

> 来源：捷粉之窝 | 发布日期：2026-03-19

## 一、如何进入事件查看器

### 方法一：通过「此电脑」右键菜单进入
1. 桌面找到「此电脑」图标 → 右键 → 「管理」
2. 计算机管理窗口 → 左侧「事件查看器」
3. 展开「Windows 日志」→ 点击「安全性」

### 方法二：运行命令快速进入
```
Win + R → 输入 eventvwr.msc 或 eventvwr → 回车
```

### 方法三：开始菜单搜索
开始菜单搜索「事件查看器」→ 点击应用

## 二、常用安全事件ID

### 系统相关事件

| Event ID | 说明 |
|----------|------|
| **1074** | 计算机开机、关机、重启时间及原因 |
| **6005** | 计算机日志服务已启动（系统正常启动） |
| **104** | 审计日志清除事件（需警惕恶意清除日志行为） |

### 安全相关事件

| Event ID | 说明 |
|----------|------|
| **4624** | 用户成功登录系统 |
| **4625** | 用户登录失败（暴力破解监控关键指标） |
| **4648** | 使用显式凭据尝试登录 |
| **4720/4722/4723/4724** | 用户账户创建、启用、密码修改、密码重置 |
| **4725/4726/4738/4740** | 用户账户禁用、删除、变更、锁定 |
| **4727/4737/4739/4762** | 用户组创建、变更、成员操作 |

## 四、安全日志分析技巧

### 1. 重点关注关键事件
- **4625** - 登录失败（暴力破解监控）
- **104** - 日志清除（安全事件追踪）
- **4740** - 账户锁定（异常行为检测）

### 2. 结合时间维度分析
使用筛选功能定位特定时间段内的安全事件。

### 3. 导出日志进行深度分析
```powershell
# 导出安全日志
wevtutil epl Security C:\SecurityLogs.evtx
```

### 4. 常用分析工具
- Windows Event Viewer Plus
- Log Parser
- 第三方 SIEM 工具
