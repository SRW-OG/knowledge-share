# 【内网渗透】土豆提权大汇总

> 🎯 适合人群：红队渗透测试人员、CTF选手、想要学习内网提权的师傅们

---

## 一、为什么要掌握？

在红队渗透测试中，**Windows 提权**是必须掌握的一部分，也是面试的**加分项**。

很多师傅们只局限于 **Web 端**的渗透，**内网提权**却一窍不通，这篇文章将会给你介绍 **Windows 中最常用的提权方法 —— "土豆家族"提权**。

---

## 二、土豆提权核心原理

**核心原理**：利用 **Windows 系统身份验证机制**和**令牌管理**的设计缺陷，通过 **NTF 反射**或**中继攻击**劫持高权限帐户（如 `NT Authority\System`）的身份验证过程，从而将低权限用户（如 Web 服务帐户、数据库服务帐户等）提升到最高的**系统权限**。

**优势**：主要依赖于系统中默认启用的**核心服务**，如 **RPC**、**DCOM**、**打印机服务**等，这些服务可以在不安装额外组件的情况下运行，在实际场景中很实用。

---

## 三、工具汇总

### 1. CoercedPotato

**项目地址**：https://github.com/Prepouce/CoercedPotato

**原理**：通过在 **Windows 10**、**Windows 11** 和 **Server 2022** 上滥用 **SeImpersonatePrivilege** 特权，可以从 `LOCAL SERVICE`/`NETWORK SERVICE` 账户提升为 **SYSTEM** 权限。

**用法**：
```cmd
.\CoercedPotato.exe -c whoami
```

---

### 2. PetitPotato

**项目地址**：https://github.com/wh0amitz/PetitPotato

**原理**：PetitPotam 利用 **MS-EFSR**（加密文件系统远程协议）—— 该协议用于对通过网络访问的远程加密数据执行维护和管理操作。

**MS-EFSR API**：
- `EfsRpcOpenFileRaw` 等 API
- 可通过 `FileName` 参数指定 **UNC 路径**
- 当指定 `\\IP\C$` 路径时，**lsass.exe** 服务将以 **NT AUTHORITY\SYSTEM** 账户权限访问 `\\IP\pipe\srvsvc`

**利用流程**：
1. 调用 `EfsRpcOpenFileRaw` API 强制本地计算机连接至恶意命名管道
2. 模拟命名管道客户端进程
3. 最终获取 **SYSTEM 权限**

**绕过补丁**：
- 旧版 PetitPotam 因相关补丁限制已无法在新版 Windows 上生效
- 在调用 EFS 前通过 `RpcBindingSetAuthInfoW` 将 `AuthnLevel` 设置为 `RPC_C_AUTHN_LEVEL_PKT_PRIVACY` 的方法可在最新系统中生效

**兼容性**：
- 可在**所有版本 Windows**上完美提权至 SYSTEM
- 已在 Windows 21H2 10.0.20348.1547 版本测试通过
