# 数据安全技术 数据分类分级规则

> 来源: 微信公众号 - 豫说网数安  
> 作者: 何威风  
> 日期: 2026-02-25

---

## 背景

2024年3月15日，国家市场监督管理总局与国家标准化管理委员会联合发布了《数据安全技术 数据分类分级规则》（GB/T 43697-2024）。

作为对《中华人民共和国数据安全法》第二十一条所确立的"国家建立数据分类分级保护制度"的核心响应与具体技术落地，该标准为我国各行业、各地区、各部门及广大数据处理者提供了统一、科学、可操作的实施指南。

---

## 一、标准定位、范围与核心原则

### 适用范围

- 为行业主管部门制定细分规范、各地区各部门开展具体工作、数据处理者实施内部管理提供通用规则
- **不适用于**国家秘密和军事数据

### 五大基本原则

| 原则 | 说明 |
|------|------|
| **科学实用原则** | 分类依据需稳定、常见，分级边界需清晰 |
| **边界清晰原则** | 不同数据级别的保护措施应有明确区分 |
| **就高从严原则** | 当多个因素可能影响分级时，以最高影响程度为准 |
| **点面结合原则** | 既考量单项数据，也须评估数据汇聚融合后的叠加或衍生风险 |
| **动态更新原则** | 建立定期审核与更新机制 |

---

## 二、数据分类：构建"行业-业务"双层认知框架

### 双层分类框架

**第一层：行业领域分类**
- 工业、电信、金融、能源、交通运输等主要行业领域
- 将数据置于国家宏观产业管理与监管的语境下

**第二层：业务属性分类（九大维度）**
- 业务领域
- 描述对象（用户数据、业务数据等）
- 流程环节
- 数据主体（公共数据、组织数据、个人信息）等

### 意义

解决了以往分类工作中维度混乱、标准不一的问题，将"数据是什么"从一个简单的标签，转变为在结构化坐标体系中进行精准定位。

---

## 三、数据分级：基于风险影响的三级保护体系

### 三级体系

| 级别 | 定义 |
|------|------|
| **核心数据** | 重要数据的子集，特指对领域、群体、区域具有较高覆盖度或达到较高精度、规模、深度，且直接影响政治安全，或关系国民经济命脉、重要民生、重大公共利益的数据 |
| **重要数据** | 可能直接危害国家安全、经济运行、社会稳定、公共健康和安全的数据 |
| **一般数据** | 除核心数据和重要数据以外的其他数据 |

### 分级要素识别

| 要素类型 | 示例 |
|----------|------|
| 定性描述 | 领域、群体、区域、重要性 |
| 定量描述 | 精度、规模、深度、覆盖度 |

### 数据影响分析

**影响对象（六个层次）：**
- 国家安全
- 经济运行
- 社会秩序
- 公共利益
- 组织权益
- 个人权益

**影响程度（三级）：**
- 特别严重危害
- 严重危害
- 一般危害

### 级别确定规则

| 影响程度 | 数据级别 |
|----------|----------|
| 对国家安全造成特别严重/严重危害 | 核心数据 |
| 对国家安全造成一般危害，或对经济运行/社会秩序/公共利益造成严重危害 | 重要数据 |
| 其他 | 一般数据 |

---

## 四、实施流程与动态治理

### 双层实施路径

**行业领域层面：**
- 主管（监管）部门制定本行业的细化标准规范
- 明确分类细则和重要数据、核心数据识别规则
- 组织本行业数据处理者开展分类分级及目录报送工作

**数据处理者层面：**
1. 数据资产梳理
2. 依据行业规范或本标准制定内部细则
3. 实施数据分类
4. 形成分类分级清单与核心/重要数据目录
5. 按要求上报

### 动态更新情形

- 数据规模、内容变化
- 融合方式变化
- 脱敏处理
- 安全事件
- 法规要求变化

---

## 五、总结与意义

| 意义 | 说明 |
|------|------|
| **统一方法论** | 结束各行业、各地区"各自为战"的局面 |
| **聚焦保护重点** | 引导将有限安全资源集中到核心数据和重要数据 |
| **实现风险量化** | 从定性走向半定量化，决策更具科学性和可审计性 |
| **衔接责任链条** | 明确分层职责与工作流程，推动协同共治 |

该标准不仅是一套技术规则，更是蕴含国家数据安全战略意志的治理工具，为数字经济在安全可信的轨道上高质量发展提供坚实保障。
