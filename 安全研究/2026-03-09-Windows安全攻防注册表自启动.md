# Windows安全攻防-注册表自启动

## 1. 启动项分类

### 用户级启动项-HKEY_CURRENT_USER

| 注册表路径 | 说明 |
|------------|------|
| `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` | 当**特定用户登录**时自动启动，只需当前用户权限即可修改 |
| `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\RunOnce` | 程序**只会自动运行一次**，运行后通常会被系统自动删除。常用于安装程序完成后的首次配置 |

### 系统级启动项-HKEY_LOCAL_MACHINE

| 注册表路径 | 说明 |
|------------|------|
| `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Run` | 当**任何用户登录**时自动启动，需要**管理员权限**才能修改，影响计算机上的所有用户账户 |
| `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce` | 程序会在**系统启动后、用户登录前**运行一次（通常需要管理员权限），运行后项被删除。常用于系统级别的安装后任务或修复 |

## 2. 相关Windows API

### GetModuleFileNameW

用于获取指定模块的完整路径文件名，在当前项目中用于获取当前程序的绝对路径。

```c
DWORD GetModuleFileNameW(
    [in, optional] HMODULE hModule,
    [out]          LPWSTR  lpFilename,
    [in]           DWORD   nSize
);
```

**参数说明：**
- `hModule`：要获取路径的模块的句柄，如果为 NULL，则返回调用进程的可执行文件路径
- `lpFilename`：接收模块路径的缓冲区
- `nSize`：指定缓冲区大小(以字符为单位)，通常使用 MAX_PATH 常量(260个字符)

**返回值：**
- 成功时：返回复制到缓冲区中的字符串长度(以字符为单位)
- 失败时：返回0，可通过 GetLastError() 获取错误信息

### SHGetKnownFolderPath

用于获取系统标准文件夹的完整路径，如获取当前用户的 Documents 目录，程序文件目录 (通常是 C:\Program Files)，桌面目录等。

```c
HRESULT SHGetKnownFolderPath(
    REFKNOWNFOLDERID rfid,
    DWORD            dwFlags,
    HANDLE           hToken,
    PWSTR            *ppszPath
);
```

**参数说明：**

1. `rfid`：这是一个 GUID 引用，标识要获取的特定已知文件夹。Windows 定义了数百个标准文件夹的 GUID：

| GUID | 说明 |
|------|------|
| `FOLDERID_Documents` | 当前用户的文档文件夹 |
| `FOLDERID_ProgramFiles` | 程序文件目录 (通常是 C:\Program Files) |
| `FOLDERID_Desktop` | 桌面目录 |
| `FOLDERID_Profile` | 用户配置文件目录 |

2. `dwFlags`：指定获取路径时的特殊选项标志

| 标志值 | 描述 |
|--------|------|
| `KF_FLAG_DEFAULT` (0x00000000) | 默认行为 |
| `KF_FLAG_NO_APPCONTAINER_REDIRECTION` (0x00010000) | 禁止应用容器重定向 |
| `KF_FLAG_CREATE` (0x00008000) | 如果文件夹不存在则创建 |
| `KF_FLAG_DONT_VERIFY` (0x00004000) | 不验证文件夹是否存在 |
| `KF_FLAG_DONT_UNEXPAND` (0x00002000) | 返回环境变量不展开的路径 |
| `KF_FLAG_NO_ALIAS` (0x00001000) | 不解析为别名路径 |
| `KF_FLAG_INIT` (0x00000800) | 初始化文件夹 |
| `KF_FLAG_DEFAULT_PATH` (0x00000400) | 获取默认路径而非当前路径 |
| `KF_FLAG_NOT_PARENT_RELATIVE` (0x00000200) | 返回绝对路径而非相对于父文件夹 |

3. `hToken`：代表用户令牌的句柄，可用于为特定用户获取文件夹路径。通常传递 NULL 表示当前用户。

4. `ppszPath`：指向接收路径字符串指针的指针。调用成功后，必须使用 `CoTaskMemFree` 释放返回的内存。

**返回值：**
- `S_OK`：成功获取路径
- `E_FAIL`：操作失败
- `E_INVALIDARG`：参数无效

## 3. 持久化攻击利用

### 攻击思路

攻击者通过在注册表启动项中添加恶意程序路径，实现目标主机重启后仍能保持控制。

### 常用位置

| 位置 | 权限要求 | 影响范围 |
|------|----------|----------|
| HKCU\...\Run | 普通用户 | 当前用户 |
| HKCU\...\RunOnce | 普通用户 | 当前用户 |
| HKLM\...\Run | 管理员 | 所有用户 |
| HKLM\...\RunOnce | 管理员 | 所有用户 |

### 检测与防御

**检测方法：**
- 使用注册表监控工具（如 Process Monitor）
- 检查上述注册表路径中的可疑项
- 使用autoruns等工具查看启动项

**防御建议：**
- 限制管理员权限
- 启用注册表监控
- 定期审计启动项
- 使用杀软/EDR检测异常启动项
