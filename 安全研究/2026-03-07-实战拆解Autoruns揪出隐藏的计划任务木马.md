# 实战拆解：Autoruns揪出隐藏的计划任务木马

## 一、实战背景

在日常的网络安全运维工作中，我们经常会遇到各种恶意软件的潜伏与伪装。本文从执行木马开始，到利用 Autoruns 发现异常计划任务，再到识破文件的隐藏手段，最后成功删除木马并总结防范经验。

---

## 二、详细步骤

### 01 打开 Autoruns

在虚拟机中双击运行了一个事先准备好的 **"shell.exe"** 程序（实际是一个会创建计划任务的后门程序）。

### 02 发现计划任务

在 Autoruns 界面中，切换到**计划任务**选项，仔细查看与之前对比，发现新建了一个计划任务：

**路径为：**
```
C:\ProgramData\WindowsTask\service.exe
```

### 03 目标文件夹为空

根据计划任务中指向的路径，打开相应的文件夹，**并未发现该程序**。

这是因为木马使用了**隐藏手段**。

### 04 使用了隐藏手段

Windows 系统中有多种隐藏文件的方法，最常见的是设置文件属性为"隐藏"或"系统文件"。

#### 方法一：文件夹选项

要查看这类文件，需要在**文件夹选项中取消勾选"隐藏受保护的操作系统文件"**

操作步骤：
1. 点击"选项"→"查看"
2. 取消勾选"隐藏受保护的操作系统文件"
3. 确定后，文件夹下就有了 `service.exe` 程序

#### 方法二：命令行

使用 cmd 命令行，切换到 WindowsTask 目录：

```cmd
attrib -s -h service.exe
```

或者使用以下命令显示所有文件（包括隐藏和系统文件）：

```cmd
dir /a
```

---

## 三、彻底删除木马

1. **删除木马文件**：直接删除 `C:\ProgramData\WindowsTask\service.exe`

2. **删除计划任务**：返回 Autoruns，将木马的计划任务条目**右键删除**

3. **确认删除**：在任务计划程序库中确认该任务已被移除

4. **验证**：重启计算机后，再次运行 Autoruns 检查，计划任务没有再生，木马被彻底清除

---

## 四、总结

### 典型木马持久化过程

1. 执行后门程序
2. 创建计划任务（实现持久化）
3. 将自身文件隐藏起来（躲避常规检测）

### 推荐工具

**Autoruns** 是排查持久化后门的利器，无论是：
- 计划任务
- 服务
- 启动项

它都能**一览无余**。
