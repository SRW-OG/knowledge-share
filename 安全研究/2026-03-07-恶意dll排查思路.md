# 恶意dll排查思路

> 适用于工控机 / 服务器 / 专用设备，无法安装杀软，无法重装系统，甚至无法升级系统和无法打补丁的情况

---

## 一、排查思路概述

一般情况下，病毒程序释放文件基本上都是在 **C 盘目录**下。在排查的过程中，首先就是要分析哪些是系统自带的可执行文件，在无法找到启动进程的场景下，先去排查这些**不是系统自带的 EXE/DLL/SYS** 文件。

---

## 二、排查工具

### 2.1 奇安信病毒查杀工具

**特点**：
- 无需安装，开机急用的病毒扫描工具
- 支持指定位置查杀
- 支持手动隔离

如果能查杀出来则能快速定位。也可以用其他厂商的病毒查杀工具尝试。

---

### 2.2 Sysinternals 套件 Sigcheck

如果不能查杀出来有问题的 dll 文件，可以尝试使用 **Sigcheck + Autoruns** 实现「标准库比对+异常筛选」。

Sysinternals 中包含了很多实用工具。

#### 导出系统目录所有文件的「签名+哈希+版本+厂商」

```cmd
sigcheck -e -s -v -h -vt C:\Windows\System32 > System32_Check_Report.txt
```

**说明**：
- 查 VT 会导致很慢，即使不查 VT 也快不到哪里去，因为要递归

| 步骤 | 命令 | 说明 |
|------|------|------|
| 1 | `sigcheck -e -s -v -h -vt C:\Windows\System32 > System32_Check_Report.txt` | 查 VT（慢） |
| 2 | `sigcheck -e -s -v -h C:\Windows\System32 > System32_Check_Report.txt` | 不查 VT |
| 3 | `sigcheck "filepath"` | 单个文件检测 |

#### 参数说明

| 参数 | 说明 |
|------|------|
| `-e` | 显示可执行文件（EXE/DLL/SYS） |
| `-s` | 递归子目录 |
| `-v` | 显示版本信息 |
| `-h` | 显示哈希（SHA256） |
| `-vt` | 联动 VirusTotal 查是否恶意（要求外网并且会很慢） |

#### 签名验证结果判断

输出结果里重点看 **Verified**：

| 状态 | 完整显示 | 含义 | 安全风险 | 典型场景 |
|------|----------|------|----------|----------|
| **有效签名** | Verified: Signed | 合法 / 未篡改的数字签名 | ✅ 低风险（但需核对发布者） | 微软系统文件，正规软件 |
| **未签名** | Verified: Unsigned | 无数字签名 | ❌ 高风险 | SecureSSDPClient.dll，黑客自制木马 |
| **伪造/无效签名** | Verified: Counterfeit / Verified: Invalid | 假签名 / 被篡改 / 证书过期 | ❌ 极高风险 | 盗用证书的恶意文件、被篡改的系统文件 |

---

### 2.3 Autoruns

**使用方法**：

直接搜索 `Verified: Unsigned` 对应的文件，快捷键 `Ctrl+F` 直接搜可疑项的名称（如 `SecureSSDPClient` 不带后缀）进行定位。

定位到引用这个 dll 的服务或者计划任务可能就是恶意的，然后执行以下操作：
1. 双击查看其注册表或者其位置
2. 将该文件上传 VT 或者微步沙箱进行恶意检测

---

### 2.4 ProcessExplorer

**使用方法**：

`Ctrl+F` 直接搜可疑项的名称，在运行中就能定位到主进程。

通常情况下有两种情况：

| 情况 | 描述 |
|------|------|
| （1）主进程位置在系统位置，进程注入 | 进程在系统目录但被注入恶意代码 |
| （2）主进程位置特殊非系统默认位置，恶意伪装程序 | 进程在非系统目录，可能是伪装的恶意程序 |

**注意**：如果遇到相关的程序和 dll 都删除了但是后续还是有进程启动，建议**重启一下电脑**，因为这些可能是在内存中需要重启释放。

## 三、文件删除

在无杀软情况下占用进程结束删除：

```cmd
del /f /q "C:\Users\admin\Desktop\样本0310\新建文件夹\SecureSSDPClient.dll"
```

---

## 四、总结

| 工具 | 用途 |
|------|------|
| 奇安信病毒查杀工具 | 快速查杀已知病毒 |
| Sigcheck | 文件签名验证、哈希计算 |
| Autoruns | 定位自启动项 |
| ProcessExplorer | 进程分析、定位主进程 |

**核心思路**：
1. 优先排查 C 盘非系统自带的可执行文件
2. 使用 Sigcheck 验证文件签名
3. 关注 `Verified: Unsigned` 和 `Verified: Invalid` 的文件
4. 结合 Autoruns 和 ProcessExplorer 定位恶意进程
