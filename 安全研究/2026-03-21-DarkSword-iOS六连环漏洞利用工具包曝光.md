# DarkSword iOS 六连环漏洞利用工具包曝光

## 1. 问题现状

### 背景描述

**DarkSword** 是一套高级 iOS 漏洞利用工具包（Exploit Kit），自 2025 年 11 月起被多个商业监控软件厂商及国家级黑客组织使用，已导致沙特阿拉伯、土耳其、马来西亚和乌克兰等地用户成为目标。

### 核心特征

- **全链式攻击**：6 个漏洞串联，覆盖 iOS 18.4 至 18.7
- **零日占比高**：6 个漏洞中 4 个在被发现时属于零日（iOS 厂商未知）
- **无用户交互**：仅需访问恶意网页即可触发，无需点击链接或安装 App
- **完全静默**：全程 JavaScript 代码执行，隐蔽性极高

### 影响范围

- **目标系统**：iOS 18.4 ~ 18.7
- **地理分布**：沙特阿拉伯、土耳其、马来西亚、乌克兰
- **威胁组织**：UNC6748（GHOSTKNIFE）、PARS Defense（GHOSTSABER）、UNC6353（GHOSTBLADE）

## 2. 解决思路与方案对比

### 六步攻击链详解

| 阶段 | 漏洞编号 | 组件 | 作用 |
|------|----------|------|------|
| 1. 初始突破 | CVE-2025-31277, CVE-2025-43529 | JavaScriptCore | Safari 代码执行 |
| 2. PAC 绕过 | CVE-2026-20700 | dyld（动态链接器）| 绕过指针认证 |
| 3. 沙盒逃逸 (1) | CVE-2025-14174 | WebGL | 第一层沙盒突破 |
| 4. 沙盒逃逸 (2) | CVE-2025-43510 | XNU 内核 | 第二层沙盒突破 |
| 5. 权限提升 | CVE-2025-43520 | 内核文件系统 | 竞争条件 → Root |
| 6. 载荷植入 | — | 系统深层 | 持久化控制 |

### 威胁组织后门对比

| 组织 | 后门名称 | 主要功能 | 传播方式 |
|------|----------|----------|----------|
| UNC6748 | GHOSTKNIFE | 账户/消息窃取、音频录制、删除崩溃日志 | 伪造 Snapchat 登录页 |
| PARS Defense | GHOSTSABER | 15+ 指令、文件窃取、数据库查询 | 商业监控 |
| UNC6353 | GHOSTBLADE | 全面信息收集：iMessage/Telegram/WhatsApp/加密货币/钥匙串/Wi-Fi 密码 | 入侵合法网站 |

### 防御方案

| 方案 | 有效性 | 实施难度 |
|------|--------|----------|
| 更新至 iOS 18.7.2 / iOS 26.1+ | ✅ 全部 6 个漏洞已修复 | 极低（用户操作） |
| 开启「锁定模式」 | ⚠️ 大幅增加攻击难度（无法完全免疫） | 低 |
| 旧设备无法更新 | ❌ 高风险，建议更换设备 | — |

## 3. 最佳实践框架

### 核心原则：及时更新是唯一有效防线

```
iOS 18.4-18.7（有漏洞）
  ├── iOS 18.7.2 → ✅ 4个漏洞修复
  └── iOS 26.1   → ✅ 全部6个漏洞修复
        └── iOS 26.3 → ✅ CVE-2026-20700（PAC绕过）修复
```

### 移动端安全基线

- **系统更新**：开启自动更新，确保第一时间修补
- **锁定模式**：在「隐私与安全性」中开启，适合高风险用户
- **应用来源**：仅从 App Store 安装，避免第三方渠道
- **网络习惯**：避免访问不明来源网站，尤其是要求登录的站点

## 4. 具体操作步骤

### 立即行动

**Step 1：检查系统版本**

```
设置 → 通用 → 关于 → iOS 版本
```

**Step 2：执行系统更新**

```
设置 → 通用 → 软件更新 → 下载并安装
```

**Step 3：开启锁定模式（可选，高安全性用户）**

```
设置 → 隐私与安全性 → 锁定模式 → 开启
```

> 注意：开启锁定模式会影响部分应用功能，请提前了解影响范围。

**Step 4：验证修复**

检查 iOS 版本是否 ≥ 18.7.2（主版本）或 ≥ 26.1（最新主版本）。

## 5. 总结与建议

### 关键要点

- **攻击复杂度极高**：DarkSword 代表了国家级攻击能力，6 个漏洞串联利用，防护难度极大
- **用户端防御有限**：唯一有效手段是及时更新系统，不给攻击者可乘之机
- **攻击者动机明确**：三个威胁组织针对不同地区部署定制化后门，目的包括商业监控和国家级情报搜集

### 漏洞修复状态

截至本文发布，所有 6 个漏洞均已在 iOS 更新版本中修复：
- CVE-2026-20700（PAC 绕过）→ iOS 26.3 修复
- 其余 5 个 → iOS 18.7.2 / 26.1 修复

### 安全建议

1. **立即更新 iOS**：所有 iOS 用户应第一时间更新至最新版本
2. **高风险用户开启锁定模式**：记者、活动人士、企业高管等目标群体
3. **警惕社交工程**：GHOSTKNIFE 通过伪造登录页传播，不要在非官方页面输入凭据
4. **关注设备提示**：iOS 安全通知不要忽视

> DarkSword 的出现标志着移动端漏洞利用已进入「工业化」阶段，零日漏洞不再是国家级专属资源，商业监控厂商同样可以获取。个人用户能做的最有效一件事，就是保持系统更新。
