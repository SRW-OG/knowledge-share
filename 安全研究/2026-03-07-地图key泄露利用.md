# 地图key泄露利用

> ⚠️ 本文仅供安全研究参考，请勿用于非法用途

---

## 一、背景

开发者在开发应用时考虑到用户登录、操作等需要定位信息，因此采用了第三方地图服务，如：
- 百度地图
- 腾讯地图
- QQ地图
- 高德地图

**关键问题**：地图 API 调用是**付费服务**，若地图 Key 泄露则可被攻击者利用脚本**恶意刷取额度**。

---

## 三、Key 有效性验证

### 3.1 可用情况

若 Key 可调用，API 会返回定位数据。

### 3.2 不可用情况

若 Key 不可用（被禁用），API 会返回相应错误信息。

---

## 四、刷取额度

攻击者获取泄露的地图 Key 后，可使用脚本**恶意刷取额度**，导致：
1. 消耗目标账户配额
2. 产生额外费用
3. 影响正常业务使用

---

## 五、防御建议

| 措施 | 说明 |
|------|------|
| **Key 保密** | 不要在前端代码中暴露地图 Key |
| **Referer 限制** | 配置 Key 的 Referer 白名单 |
| **IP 限制** | 绑定 Key 到特定服务器 IP |
| **额度监控** | 定期检查 API 调用量和费用 |
| **及时更换** | 发现异常及时更换 Key |
