## 三、小程序逆向实战

### 3.1 定位字段

某医院小程序的请求特征：
- `X-Api-Key`：防止重放
- `X-Auth-Token`：鉴权
- `X-Hos-Id`、`X-Traffic`、`X-Api-Ver`、`X-Main-User-Id`
- `Request-No`：时间戳（17开头）

### 3.2 定位加密代码

**搜索关键字**：`X-Api-Key`

```javascript
"X-Api-Key": (0, a.default)(e, t, n)
```

追踪 `a` 模块，通过 Webpack 打包的编号定位。

### 3.3 X-Api-Key 生成算法

**完整算法流程**：

```
请求 URL + method
    ↓
提取 path + query
提取指定 headers 顺序拼接
提取 body（若满足条件）
    ↓
拼接字符串: A && B && C
    ↓
MD5 hashDigest
    ↓
构建签名体（含 timestamp、uuid、digest 等）
    ↓
AES-CBC 加密 + Pkcs7 + Base64
    ↓
设为 X-Api-Key 头部
```

**签名体结构**：
```json
{
  "accessEntry": "patient",
  "apiKey": "xxxxx",
  "timestamp": 1710000000000,
  "replayNo": "ec5c-fbc1-58ad-48a1",
  "hashDigest": "md5_hash_value"
}
```

**hashDigest 计算**：
```javascript
hashDigest = MD5(pathAndQuery + "&&" + headerDigest + "&&" + dataDigest)
```

**参与计算的 Headers**：
```javascript
['X-User-Id', 'X-Hos-Id', 'X-Auth-Token', 'X-Api-Ver']
```

### 3.4 逆向坑点

**坑点一**：iv 和 key 来源
- 代码中 `e[n(469)] || o` 和 `e.iv || c` 是或运算
- 实际 key 和 iv 来自字符串列表映射
- 直接跟踪 e 会浪费大量时间

**坑点二**：AI 辅助逆向的陷阱
- AI 给出的映射可能不准确
- 需手动动态调试确认
- 注意代码中的 `a.push(a.shift())` 动态数组操作

## 四、自动化脚本

### 4.1 核心生成代码 (JavaScript)

```javascript
function generateXApiKey({ url, method = 'GET', headers = {}, data = null, timestamp, uuid, debug = false }) {
    const ts = typeof timestamp === 'number' ? timestamp : Date.now();
    const rid = typeof uuid === 'string' ? uuid : uuidv4();
    const hashDigest = buildHashDigest({ url, method, headers, data });
    
    const payload = {
        accessEntry: 'patient',
        apiKey: E_API_KEY,
        timestamp: ts,
        replayNo: rid,
        hashDigest: hashDigest
    };
    
    const encrypted = CryptoJS.AES.encrypt(
        CryptoJS.enc.Utf8.parse(JSON.stringify(payload)),
        CryptoJS.enc.Utf8.parse(KEY),
        {
            iv: CryptoJS.enc.Utf8.parse(IV),
            mode: CryptoJS.mode.CBC,
            padding: CryptoJS.pad.Pkcs7
        }
    ).toString();
    
    return { xApiKey: encrypted, payload };
}
```

    ↓
[Burp Proxy 监听 127.0.0.1:8080]
