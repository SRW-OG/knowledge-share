# 微信4.x 小程序注入 JSRPC 与调用 wx.cloud

## 1. 问题现状 (Current Status & Problem Analysis)

### 背景描述

微信小程序安全性测试中，经常需要对小程序的业务逻辑进行动态调试和 RPC 调用。微信 4.x 版本相较于之前的版本，在调试机制上有较大变化，开发者需要了解如何在新的版本中进行小程序注入和云函数调用。

### 风险评估

- **封号风险**：非正规开启小程序调试有封号风险，测试需谨慎
- **调试复杂度**：微信 4.x 版本的调试机制与之前版本存在差异
- **环境依赖**：需要正确配置 JSRPC 环境

### 影响范围

- 微信小程序安全测试人员
- 小程序渗透测试工程师
- 安全研究爱好者

---

## 2. 解决思路与方案对比 (Solution Options & Analysis)

### 方案一：开启微信调试模式 + wx.cloud 调用

**核心思路**：通过 `wx.setEnableDebug` API 开启调试模式，然后在控制台直接调用云函数。

**优点**：
- 官方支持的方式
- 操作简单，直接调用 wx.cloud 即可

**缺点**：
- 需要手动开启
- 部分版本可能存在限制

### 方案二：JSRPC 注入

**核心思路**：利用 JSRPC 工具进行小程序注入，实现远程过程调用。

**优点**：
- 功能强大，可自定义 RPC 行为
- 支持更复杂的调用场景

**缺点**：
- 配置相对复杂
- 需要额外的环境搭建

### 方案对比

| 方案 | 难度 | 功能性 | 安全性 | 适用场景 |
|------|------|--------|--------|----------|
| wx.setEnableDebug | 低 | 中 | 高 | 基础云函数调用 |
| JSRPC 注入 | 中 | 高 | 中 | 复杂调用场景 |

---

## 3. 最佳实践框架 (Best Practice Framework)

### 方案选择

**推荐方案一 + 方案二结合使用**：
1. 优先使用官方调试模式（`wx.setEnableDebug`）进行基础调试
2. 复杂场景使用 JSRPC 注入

### 架构设计

```
微信小程序
    ├── wx.setEnableDebug 开启调试
    │       └── vconsole 控制台
    │               ├── 直接调用 wx.cloud.callFunction
    │               └── JSRPC socket 连接
    │                       └── 远程 RPC 调用
    └── globalThis.socket.regAction
            └── 自定义 RPC Action
```

### 关键组件

- **wx.setEnableDebug**：微信官方调试开启 API
- **vconsole**：微信内置调试面板
- **JSRPC**：小程序 RPC 注入工具（https://github.com/jxhczhl/JsRpc）
- **wx.cloud**：微信云开发 API

## 4. 具体操作步骤 (Implementation Steps)

### 前置准备

- 微信版本 ≥ 4.x
- JSRPC 工具（从 https://github.com/jxhczhl/JsRpc 获取）
- 目标小程序

### Step 1: 开启调试模式

在微信小程序控制台或通过代码调用：

```javascript
wx.setEnableDebug({
  enableDebug: true
})
```

官方文档：https://developers.weixin.qq.com/miniprogram/dev/api/base/debug/wx.setEnableDebug.html

### Step 2: 打开 vconsole

开启调试后，底部会出现 vconsole 入口，点击即可打开调试面板。

### Step 3: 调用 wx.cloud

在 vconsole 控制台中直接调用云函数：

```javascript
wx.cloud.callFunction({
  name: 'getTags',
  data: {
    event: '',
    data: {
      page: 1,
      pageSize: 10
    }
  }
}).then(res => console.log(res.result))
  .catch(err => console.error(err));
```

### Step 4: JSRPC 注入配置

**启动 JSRPC 服务**：
参考 https://github.com/jxhczhl/JsRpc

**配置 JSRPC 全局对象**：

```javascript
globalThis.one = this.sm2Encode;
```

**注册自定义 Action**：

```javascript
globalThis.socket.regAction("two1", function (resolve, param) {
  try {
    let result = param['data']; // param 部分填参数
    resolve(result);
  } catch (e) {
    resolve(`调用失败: ${e.message}`);
  }
});
```

**发起 RPC 调用**：

```
http://127.0.0.1:12080/go?group=two&action=two1&param={"data":"hello,jsrpc"}
```

### Step 5: 关闭调试

在 vconsole 中点击「关闭调试」按钮，关闭后需重启微信生效。

## 5. 总结与建议 (Summary & Recommendations)

### 成效回顾

- 成功在微信 4.x 版本中开启调试模式
- 实现了云函数 wx.cloud 的直接调用
- 通过 JSRPC 完成了自定义 RPC 注入

### 关键要点

1. **多看官方文档**：答案往往就在官方文档中
2. **谨慎操作**：非正规调试有封号风险，测试需谨慎
3. **结合使用**：根据场景选择 wx.setEnableDebug 或 JSRPC
