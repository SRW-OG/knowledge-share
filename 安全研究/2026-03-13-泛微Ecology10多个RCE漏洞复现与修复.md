## 修复方案

### 官方修复方案

联系泛微官方售后支持，获取最新 **E10安全补丁包 v20260312**。

### 临时缓解措施

1. **避免公网暴露**：如非必要，不将资产暴露在互联网
2. **配置 nginx 授权**：在 `nginx` 中为 `/papi/` 路径配置 **Basic Auth**（最常用、最简单）

```nginx
location /papi/ {
    auth_basic "Restricted Access";
    auth_basic_user_file /etc/nginx/.htpasswd;
}
```
