## 概述

堡垒机是**运维入口**与**安全审计核心枢纽**，是等保 2.0 网络安全合规检查的**必查重点**。

本文包含 **16 项关键检查点**，可直接作为安全巡检表、等保自查表、加固方案使用。

---

## 一、远程管理安全

### 1.1 登录方式
- **优先采用 HTTPS 安全连接**
- 仅初次配置时使用 Console 口，日常管理禁用

### 1.2 限制登录闲置超时
- **管理员 → 系统配置 → 认证配置**
- Web 超时时间设置为 **600 秒（10 分钟）**

### 1.3 关闭无关服务
- **管理员 → 系统配置 → 引擎**
- 仅开启**数据库审计服务**，其余全部关闭

---

## 二、用户账号与口令安全

### 2.1 账号和密码管理
**必须修改系统默认初始账号密码**：

| 账号 | 角色 |
|------|------|
| weboper | 管理员 |
| webaudit | 审计员 |
| conadmin | Console 账号 |

> 内置账号不允许改名，**首次配置后立即修改默认密码**

### 2.2 密码策略加固

| 项目 | 要求 |
|------|------|
| 密码最短长度 | ≥8 位 |
| 密码复杂度 | 字母 + 数字/特殊字符，至少两种组合 |
| 密码有效期 | 每 3 个月强制更换一次 |

### 2.3 登录安全控制
- **管理员 → 系统配置 → 参数配置**
- 登录尝试次数设为 **5 次**，防止暴力破解

---

## 三、日志与审计安全

### 3.1 管理权限分离
- 仅 **webaudit 审计员**可查看/审计操作日志
- 其他账号无审计权限，实现**管理与审计分离**

### 3.2 安全审计覆盖范围

| 类别 | 内容 |
|------|------|
| 终端类型 | 字符终端、图形终端、FTP 传输 |
| 日志类型 | 事件日志、登录日志、改密日志、策略变更日志 |
| 审计内容 | 登录/退出时间、客户端 IP、用户名、目标主机地址/账号 |

### 3.3 审计记录存储
- 系统**自动存储、自动备份**审计日志
- 内置硬盘满足长期存储，满盘后导出至外部介质
- 满足**等保要求：日志长期留存**

---

## 四、网络与安全防护

### 4.1 端口最小化开放

| 端口 | 用途 |
|------|------|
| 443 | HTTPS |
| 22 | SSH |

- 仅开放必要端口
- 防火墙策略封禁其他所有端口
