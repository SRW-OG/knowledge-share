# Windows无杀软手工应急处置方案(工控机/专用设备)

> 适用于工控机 / 服务器 / 专用设备，无法安装杀软，无法重装系统，甚至无法升级系统和无法打补丁的情况

---

## 一、命令行解决

### 步骤 1：文件查找

使用 **Everything** 搜索文件位置。

若文件夹下看不到文件，检查隐藏文件：

| 命令 | 说明 |
|------|------|
| `dir /a` | 显示被隐藏的文件 |
| `attrib -h -s /s /d` | 去除隐藏和系统属性 |

已知文件名及文件路径的情况下找对应的 PID。

---

### 步骤 2：按文件路径找进程 PID

打开**管理员 CMD**，运行以下命令（把目标文件路径换成你要杀的文件）：

```cmd
wmic process where "ExecutablePath='C:\\Windows\\SysWOW64\\svchost.exe'" get ProcessId,Name,ExecutablePath
```

**示例（杀 wmiex.exe）：**

```cmd
wmic process where "ExecutablePath='C:\\Windows\\SysWOW64\\wmiex.exe'" get ProcessId,Name
```

输出结果示例：

```
Name       ProcessId
wmiex.exe  7476
```

**关键技巧**：进程名伪装成 `svchost.exe`，但是路径是恶意的，就能精准揪出来。

---

### 步骤 3：强制结束该 PID 的进程（无视"进程保护"）

用 `taskkill` 加 `/f /t` 参数（`/f` 强制结束，`/t` 结束子进程）：

```cmd
taskkill /f /t /pid 7476
```

**备用方案（如果上面杀不掉）：**

```cmd
wmic process where ProcessId=7476 delete
```

---

### 步骤 4：删除恶意文件

进程结束后，立刻删除文件（加 `/f /q` 强制删除、静默删除）：

```cmd
del /f /q "C:\Windows\SysWOW64\wmiex.exe"
```

**若提示"文件正在使用"（还有残留）：**

用 `rd /s /q` 删除目录（如果是文件夹里的恶意文件），或进安全模式删；也可以用下面的命令标记"重启后删除"：

```cmd
move /y "C:\Windows\SysWOW64\wmiex.exe" "C:\Windows\Temp\tmp_del.exe"

reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager" /v PendingFileRenameOperations /t REG_MULTI_SZ /d "\??\C:\Windows\Temp\tmp_del.exe\0\??\C:\Windows\Temp\tmp_del.exe\0" /f
```

## 二、针对文件夹的解除占用

夺回文件夹的所有权 + 给管理员账户分配「完全控制」权限

### 步骤 1：获取文件夹所有权

```cmd
takeown /f "C:\Windows\NetworkDistribution" /r /d y
```

### 步骤 2：分配完全控制权限

```cmd
icacls "C:\Windows\NetworkDistribution" /grant administrators:F /t
```

### 步骤 3：强制删除

```cmd
rmdir /s /q "C:\Windows\NetworkDistribution"
```

**参数解释：**
- `rmdir` = 删除文件夹
- `/s` = 连里面所有东西一起删
- `/q` = 安静强制删，不弹确认

## 三、Sysinternals 工具

### 1. procexp.exe

**强制杀任何进程（无视保护）**

- 以管理员身份运行
- 找到可疑进程
- 右键 → Kill Process

### 2. autoruns.exe

查看开机启动项，检查可疑的自启动程序。

### 3. Sigcheck

验证文件签名（详见另一篇文章《恶意dll排查思路》）。

---

## 四、总结

| 阶段 | 关键命令 |
|------|----------|
| 查找文件 | Everything / `dir /a` |
| 找进程 | `wmic process where ...` |
| 杀进程 | `taskkill /f /t /pid xxx` |
| 删文件 | `del /f /q` 或 `rd /s /q` |
| 解权限 | `takeown` + `icacls` |
| 强力工具 | procexp.exe / autoruns.exe |
