## 二、MCP（模型上下文协议）

### 什么是 MCP

由 Anthropoc 2024年11月底推出的一种开放标准，旨在统一大模型与外部数据源和工具之间的通信协议。

**作用**：即使模型不支持 Function Call，也可以进行工具调用

### 使用 MCP

1. **客户端**：https://www.pulsemcp.com/clients 推荐使用 **5ire**
2. **服务端**：填写 API-Key（推荐 DeepSeek API，费用便宜）

### 编写 MCP 服务

使用 **fastmcp** 框架（Python）：

```python
from fastmcp import FastMCP
from datetime import datetime
import platform
import time

mcp = FastMCP("Local Time Service")

@mcp.tool()
def get_local_time() -> dict:
    """获取当前计算机的本地时间信息"""
    now = datetime.now()
    return {
        "local_time": now.strftime("%Y-%m-%d %H:%M:%S"),
        "timestamp": int(now.timestamp()),
        "timezone": time.tzname,
        "system": platform.system(),
        "node": platform.node()
    }

if __name__ == "__main__":
    mcp.run()
```

## 三、MCP 在逆向工具中的应用

### 1. IDA Pro

**MCP**：[mrexodia/ida-pro-mcp](https://github.com/mrexodia/ida-pro-mcp)

**安装步骤**：

```bash
# 1. 激活 IDA 的 Python 环境
idapyswitch.exe --force-path .\python313\python3.dll

# 2. 安装 MCP
pip uninstall ida-pro-mcp
pip install https://github.com/mrexodia/ida-pro-mcp/archive/refs/heads/main.zip
ida-pro-mcp --install

# 3. 复制插件到 IDA 目录
# 把 AppData\Roaming\Hex-Rays\IDA Pro\plugins 下的 ida_mcp 和 ida_mcp.py 剪切到 ida.exe 文件夹下的 plugins

# 4. 在 5ire 中配置
python C:\Develop\Python\python3.14.2\Lib\site-packages\ida_pro_mcp\server.py --ida-rpc http://127.0.0.1:13337
```

**使用**：
1. 打开 IDA
2. Edit → Plugins → MCP 打开
3. 在 5ire 中提问
