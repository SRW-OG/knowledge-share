# SRC漏洞挖掘经验：吃透比学完重要

## 核心观点

> **学习的本质在于吃透，不在于学完。**

- 学完 = 信息堆积（刷视频、收藏课程）
- 吃透 = 能力生长（能用自己话讲清楚原理、能独立复现攻击、能举出实战例子）

## 常见学习误区

| 误区 | 表现 |
|------|------|
| 囤积资源 | 500G课程、收藏夹塞满、星球订阅五六个 |
| 只看不练 | 看完教程，下一页讲什么忘了 |
| 浅尝辄止 | 刷完靶场，说不出漏洞核心原理 |

**残酷事实：SRC只为你挖到的漏洞买单，不为你学过的课程买单。**

## 正确的学习方法：死磕一个漏洞类型

**核心策略：选一个漏洞类型，最少死磕20遍**

以越权漏洞为例：
1. 看 OWASP 官方文档
2. 翻历史漏洞案例（越权类）
3. 自己搭环境，一遍遍改 Cookie、改参数
4. 一条请求发出去，没绕过，再改
5. 还是没绕过，回头看原理

**最终目标：漏洞变成肌肉记忆 / 条件反射**

## 验证是否"吃透"的三问

1. **能不能用自己的话，把漏洞原理讲清楚？**
2. **能不能在实际测试中，复现出这个攻击手法？**
3. **能不能举出自己挖到的真实例子？**

如果做不到 → 别急着往下学，回头把它吃透。

## 效率对比

| 策略 | 结果 |
|------|------|
| 学10个漏洞类型，每个只懂皮毛 | 积累感很强，实际产出为零 |
| 吃透2个漏洞类型，每个都能挖出高危 | 月入过万 |

**别贪多，别收藏。选一个当下最有用的，死磕它、用它、验证它。**
